Около каждого уровня стоит иконка с информацией. При наведении показывает описание уровней. Еще правее кнопка со знаком бесконечности - такой же уровень, но после окончания уровня сразу начинается такой же. Рекорды засчитываются. Горячие клавиши : + / - — увеличить/уменьшить масштаб таблицы. -- Левый/правый Alt (AltGr) + B / И — открыть/закрыть окно информации. -- Левый/правый Alt (AltGr) + U / Г — включить/выключить глаз (отображается только на уровне с квадратами). -- Левый/правый Alt (AltGr) + K / Л — уменьшить прозрачность глаза (минимум 10%). -- Левый/правый Alt (AltGr) + L / Д — увеличить прозрачность глаза (максимум 100%). -- Левый/правый Alt (AltGr) + P / З — увеличить размер значка глаза -- Левый/правый Alt (AltGr) + O / Щ — уменьшить размер значка глаза. -- R / К (удерживать нажатой кнопку. работает только в меню) — показать рекорды для уровня -- Правая кнопка мыши (удерживать) — показать подсказку с искомым числом. -- Средняя кнопка мыши (удерживать, уровни 13–16) — показать все ещё не найденные цифры. -- Левый/правый Alt (AltGr) + H / Р (удерживать, уровни 13–16) — показать все ещё не найденные цифры. -- Колесо мыши вверх — выйти в меню -- Space / Колесо мыши вниз — начать заново текущую таблицу -- Перо: удерживать и провести вверх — выйти в меню; вниз — обновить таблицу (порог — 1/4 высоты окна, диагональ тоже работает). -- N / Т — открыть окно ввода таймера обратного отсчёта (Enter — запустить после ввода). -- Левый/правый Alt (AltGr)+R / Alt+К - Только во время игры на бесконечных уровнях - показывает время ПОСЛЕДНЕГО завершённого прохождения текущей таблицы. Горячие клавиши клеток (с 2×2 по 5×5) Используются физические клавиши клавиатуры (работают независимо от раскладки). Каждая клавиша соответствует положению клетки в таблице. пример 5 на 5 таблица: -- строка 1(1й сверху ряд квадратов) - Й Ц У К Е(Q W E R T) - каждая буква соответствует своему квадрату. "й" - 1й квадрат слева первого ряда, "ц"- 2й квадрат слева первого ряда, "у" - 3й квадрат слева первого ряда и тд -- строка 2(2й сверху ряд квадратов) - Ф Ы В А П(A S D F G) - каждая буква соответствует своему квадрату. "ф" - 2й квадрат слева второго ряда, "ы"- 2й квадрат слева второго ряда, "в" - 3й квадрат слева второго ряда и тд для остальных таблиц 2×2: Й Ц / Ф Ы 3×3: Й Ц У / Ф Ы В / Я Ч С 4×4: Й Ц У К / Ф Ы В А / Я Ч С М / Н Г Ш Щ Удаление рекордов: - Shift+2 удаляет у 2x2 только на этом уровне - Shift+3 удаляет у 3x3 только на этом уровне Shift+4 удаляет у 4x4 только на этом уровне Shift+5 удаляет у 5x5 только на этом уровне Shift+6 удаляет у 6x6 только на этом уровне Shift+7 удаляет у 7x7 только на этом уровне Shift+8 удаляет у 8x8 только на этом уровне Shift+9 удаляет у 9x9 только на этом уровне Shift+0 удаляет у 10x10 только на этом уровне
